# 点つなぎ 試作

index.htmlだけで動きます。外部ライブラリ・画像・通信・ログインは不要です。

全15種類、各30～50点。さかな・ちょう・かたつむり・かめ・うさぎ・ねこ・ぞう・とり・くじら・かに・はな・ふね・ロケット・いえ・でんしゃ。添付の点つなぎ教材の構成（近い点の連続、折り返し、異なる番号の近接、長短のある移動、最初から描かれた手掛かり）を参考にしたオリジナルの座標・絵です。添付PDFや画像は配布ファイルに含めていません。

## 公開先

リポジトリ: https://github.com/wkoshi0211-coder/ten-tsunagi-app
GitHub Pages: https://wkoshi0211-coder.github.io/ten-tsunagi-app/
公開設定は main ブランチの / (root) です。このURLをQRコードにしてiPadで読み取ります。

ブラウザでindex.htmlを開くとPCで試せます。iPadではGitHub PagesのURLをSafariで開き、横向きで使用してください。

## 先生の設定

- 1回1枚または3枚。3枚は選んだ課題と、それ以外から重複なく選んだ2種類に取り組みます。
- 次の数字の表示：初期設定OFF。
- 次の点を常に光らせる：初期設定OFF。
- 生徒画面にヒント・もどるボタンはありません。
- 別の番号を押しても線が増えず、減点も音もありません。
- 完成した線を残して薄い色が加わります。別の完成画像への置き換えではありません。

10分は保証していません。必要な声かけ、探し続けて止まる場所、誤タップ、実際の所要時間を見て調整します。iPad実機の表示・押しやすさは実際に確認してください。

## 数字の配置（改訂）
数字の中心は対応する点から18～24以内（SVG上の座標）に固定し、数字を遠くへ移動する処理をなくしました。短い補助線でも対応を示します。数字同士が重ならないよう近接する点も局所的に調整しています。

全15課題について横向き1024×768のブラウザで、点と数字のタップ・誤タップ・完了を確認しました。数字の枠同士の重なりは0でした。

## 画面全体を使う版
課題選択は横向きで5列×3行。点つなぎはブラウザの表示領域全体に拡大し、絵の周囲の余白も縮めています。縦横比は保っています。Safariのアドレス欄などはブラウザ側の領域です。

教師用設定は画面右下の隅36px四方を約1.6秒長押しすると開きます。通常のタップでは開きません。PCではその領域にフォーカスしてShift+Enterでも開けます。
